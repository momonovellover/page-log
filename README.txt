ページログ（個人用PWA）
=========================

内容
- 毎日の勉強ページ数の記録・編集・削除
- 月ごとの合計、先月との差、1日平均、月末予測
- 月カレンダーと日ごとのグラフ
- 年間合計、平均、月別グラフ
- CSVバックアップの書き出し・読み込み
- 対応環境ではホーム画面への追加とオフライン起動

ホーム画面に追加するには
1. このフォルダ内のファイルを、HTTPS対応の静的ホスティングサービスにアップロードします。
2. 公開されたURLをAndroidのChromeで開きます。
3. Chromeの「︙」メニューから「ホーム画面に追加」または「アプリをインストール」を選びます。

注意
- HTMLファイルを端末で直接開いただけでは、PWAインストールやオフライン機能が動かない場合があります。HTTPSのURLで公開してください。
- 記録はブラウザのローカルストレージに保存されます。ブラウザデータ削除や端末変更に備え、CSVバックアップを定期的に保存してください。
- このアプリは個人用の記録ツールです。記録データはサーバーに送信しません。
- CSVの列は date,pages です。
